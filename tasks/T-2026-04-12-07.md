## Alcance

Implementar componentes React que consumen datos del backend y renderizan la UI.

## Componentes

### DocumentUploader
- Zona de drag & drop para archivos (PDF, JPG, PNG, TXT, MD)
- Límite 10MB por archivo
- Validación de tipo MIME
- Textarea alternativa para pegar texto
- Al soltar/subir: inicia procesamiento client-side (Fase 4)
- Muestra resultados del matching

### CertificateCard
- Tarjeta con: nombre, entidad, propósitos, enlace al portal
- Badge si es obligatorio para menores (Ley 1918)
- Tiempo estimado y vigencia

### CertificateList
- Lista/grid de CertificateCards
- Filtro por propósito (laboral, educativo, contratación, personal)
- Búsqueda por texto

### AdminPanel
- Tabla de certificados con acciones (crear, editar, eliminar)
- Tabla de tickets pendientes con aprobar/rechazar
- Protegido: redirige a /login si no es admin

### TicketForm
- Campos: descripción del trámite solicitado
- Campo honeypot oculto (CSS display:none)
- Feedback al usuario tras envío

### Login
- Formulario login (email + password)
- Formulario registro (email + password + confirmar)
- Toggle entre login y registro

## Criterio de aceptación

- [x] Cada componente en su propio archivo
- [x] Props destructuradas
- [x] API calls en services/api.js, no en componentes
- [x] Estilos via clases en styles.css
- [x] Honeypot invisible al usuario pero presente en DOM
- [x] Archivos ≤ 300 líneas, funciones ≤ 20 líneas
