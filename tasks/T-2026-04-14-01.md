# T-2026-04-14-01 — PDF via canvas + OCR

**Estado:** completada
**Fase:** 4 — Procesamiento client-side (corrección)
**Dependencias:** T-2026-04-12-08

## Problema

pdfjs-dist requiere cargar un Web Worker externo que falla tanto desde CDN como
desde rutas locales en el entorno Docker/Vite actual.

## Decisión

Tratar el PDF como imagen:

1. pdf.js renderiza cada página en un `<canvas>` (sin worker externo — modo fake)
2. Cada canvas se convierte en `Blob` de imagen
3. Tesseract.js hace OCR sobre esa imagen (ya funcionando)
4. Se concatena el texto de todas las páginas

## Ventajas

- Elimina la dependencia del Web Worker de pdfjs-dist
- Funciona para PDFs escaneados (imágenes) y PDFs con texto
- Un solo pipeline de OCR para imágenes y PDFs
- Tesseract.js ya está instalado y probado

## Criterio de aceptación

- [ ] PDF se renderiza página a página en canvas
- [ ] Cada página pasa por Tesseract.js
- [ ] Texto concatenado del PDF completo
- [ ] Sin dependencia de workerSrc externo
