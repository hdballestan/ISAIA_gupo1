# T-2026-04-12-08 — Procesamiento client-side (OCR, PDF, matching)

**Estado:** completada
**Fase:** 4 — Procesamiento client-side
**Dependencias:** T-2026-04-12-05, T-2026-04-12-07

## Alcance

Implementar extracción de texto y matching de certificados enteramente en el navegador.

## Módulos

### services/pdf.js
- Usa pdf.js (pdfjs-dist) para extraer texto de PDFs
- Entrada: File object (del drag & drop)
- Salida: string con texto concatenado de todas las páginas
- Manejo de errores (PDF protegido, corrupto)

### services/ocr.js
- Usa Tesseract.js para OCR de imágenes (JPG, PNG)
- Entrada: File object
- Salida: string con texto reconocido
- Idioma: español (spa)
- Mostrar progreso al usuario (Tesseract emite eventos de progreso)

### utils/matcher.js
- Misma lógica que backend/services/matcher.py pero en JavaScript
- Recibe texto + catálogo (previamente cargado del backend)
- Normaliza texto: lowercase, eliminar tildes, colapsar espacios
- Aplica regex_patterns de cada certificado
- Devuelve array de certificados que matchearon

## Flujo integrado en DocumentUploader

1. Usuario suelta archivo en zona de drop
2. Detectar tipo: PDF → pdf.js | imagen → ocr.js | texto → directo
3. Extraer texto
4. Obtener catálogo del backend (cache en memoria)
5. Ejecutar matcher.js contra catálogo
6. Renderizar resultados como CertificateCards

## Criterio de aceptación

- [x] PDF: extrae texto de documento de prueba
- [x] OCR: extrae texto de imagen legible de prueba
- [x] Matcher: identifica ≥1 certificado en texto de prueba
- [x] Progreso visible durante OCR (no UX bloqueada)
- [x] Documentos nunca salen del navegador
- [x] Funciones ≤ 20 líneas, módulos ≤ 300 líneas
