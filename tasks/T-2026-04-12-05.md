## Alcance

Implementar el motor de matching por regex que identifica certificados en texto extraído de documentos.

## Diseño

Cada certificado en el catálogo tiene un campo `regex_patterns` (array de strings). El matcher:

1. Recibe texto plano (ya extraído del documento)
2. Normaliza: lowercase, eliminar tildes, colapsar espacios
3. Aplica cada patrón de cada certificado contra el texto
4. Devuelve lista de certificados que matchearon con metadata completa

## Patrones ejemplo

| Certificado | Patrones |
|---|---|
| Antecedentes judiciales | `antecedentes?\s+judiciales?`, `policia\s+nacional`, `certificado.*judicial` |
| Antecedentes disciplinarios | `antecedentes?\s+disciplinarios?`, `procuraduria` |
| Registro inhabilitados menores | `ley\s*1918`, `inhabilitad.*menores`, `icbf` |
| Antecedentes fiscales | `antecedentes?\s+fiscales?`, `contraloria` |
| Antecedentes penales | `antecedentes?\s+penales?`, `fiscalia` |

## Funciones

- `normalize_text(text: str) -> str` — limpia texto para matching
- `match_certificates(text: str, catalog: list) -> list` — retorna matches con score
- `get_patterns_for_certificate(cert: dict) -> list` — compila patrones regex
