## Notas

- GET /api/v1/certificates soporta filtro por propósito (?purpose=laboral)
- POST /api/v1/extract recibe solo texto plano (no archivo), aplica regex matcher y devuelve certificados
- POST /api/v1/tickets valida rate limit + honeypot antes de crear
- Todos los endpoints usan Pydantic schemas para entrada/salida
- Contrato de error común: `{ "error": { "code", "message", "details" } }`
